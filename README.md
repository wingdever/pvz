# PvZ Turn-Based

**这是玩家入口**：怎么跑起来、怎么玩、出问题怎么办。

> **文档构成见 `docs/INDEX.md`**（哪份文档回答什么、谁是业主）。本文**不复述规则与数值**：
> 规则语义（回合、行动点、召唤、卷轴、融合、花园、战役…）以 **`PROMPT.md`** 为准；
> 数值以 **`data/units/*.csv`**、**`data/items.csv`**、**`data/level/*.json`** 为准；
> **有哪些关卡 / 关卡叫什么名字**以 **`data/levels.csv`** 为准（P97：不在表里的 json 不算关卡；
> 名字 / 中文名 / 难度 / 音乐这四格也只在表里，关卡 json 里没有它们）。

## 运行

1. 需要 **Godot 4.7.x**（开发环境为 4.7.2）。
2. Godot 启动器 → **Import** → 选择本目录的 `project.godot` → **Import & Edit**。
3. 按 **F5**（或右上角 ▶）。首个场景即 `main.tscn`。

场景文件只是一个空 `Node2D`；棋盘、单位、HUD 全部在运行时由 GDScript 构建。

## 外部资产与首次构建（clone 后必读）

本仓库**只追踪第一来源**（源码、设计文档、数据表、SVG 贴图、资产清单）。
体积大的**外部资产不打包进 git**（`.gitignore` 已忽略）：

| 资产 | 位置 | 仓库里保留的 | 代码怎么引用 |
|---|---|---|---|
| 音频（173 个 `.wav`，约 619 MB） | `assets/audio/` | `assets/audio/readme.md` 清单 | `scripts/balance/balance_audio.gd` 的曲目表 / cue 表按文件名 `load()` |
| 中文字体（CJK `.ttf`/`.otf`） | `assets/fonts/` | 无（目录可空） | `scripts/ui/ui_font.gd` 扫目录取第一个可导入字体 |
| 第三方插件 `addons/curved_lines_2d/` | `addons/` | 无（本段即锚信息） | 5 个单位视图 `.tscn` 的 `ext_resource` 指向它的 `.gd` |
| Godot 导入元数据 `*.import` / `*.uid` | 各素材 / 脚本旁 | 无 | 编辑器导入时自动重建 |

**首次构建**：clone 后①把自备的 `.wav` 按 `assets/audio/readme.md` 的清单放进
`assets/audio/`；②把任一 CJK `.ttf`/`.otf` 放进 `assets/fonts/`；③重新取得第三方插件
**Scalable Vector Shapes 2D v2.34.5**（MIT，见其 `plugin.cfg` 的 `name`/`version`/`author`；
从 Godot 生态按该名称与版本自行获取，放回应为 `addons/curved_lines_2d/`）；
④用 Godot 打开工程导入一次（会自动重建 `.import` / `.uid` 与 `.godot/` 缓存）。

**已知后果（接受外部资产不入仓的代价）**：仓库里没有这些资产时游戏**仍能启动**，
但音乐会静音（`[Music] cannot load …`），中文界面会**整体回落英文**
（`Loc.prefer_zh()` 为 false，避免豆腐块）。**但缺第三方插件更严重**：5 个单位视图场景
（`scenes/units/plants/{peashooter,blaze_pepper,pepperking,spikerock}_view.tscn`、
`scenes/units/humans/human.tscn`）的 `ext_resource` 找不到插件脚本，会**加载失败**——
必须按上面第③步补回插件才能打开这些场景。排障见 `docs/DEV.md` §排障对应行。
音视频/字体属人工在外部制作或采购的资产，第三方插件属可下载的外部代码，
均非本仓库第一来源，故按 `repo-slim` 判据一律忽略、不打包。

**历史档案同样不打包**：`docs/history/`（P0–P27、P28、P37–P82、P83–P110 与乱斗 B1–B22）
是"当时怎么回事"的批次叙事，**已忽略、本地保留、不追踪**。公开 clone **失去这份速查**：
活文档（`AGENTS.md` §4、`docs/INDEX.md`、`docs/OPEN_ITEMS.md`、`docs/OPTIMIZATIONS.md`、
`docs/PITFALLS.md`、`docs/STATE.md`、`docs/UNIT_ART.md`）里所有 `docs/history/...§N` 引用
都是**已知死链**（各文件开头已显式标注「本地保留、不追踪」）。现状一律以 `docs/STATE.md`
为准，历史脉络以代码注释里的 `[P<n>]` / `[B<n>]` 标记为准。
`scripts/core/doc_check.gd` 在该目录缺失时会静默跳过档案相关断言，**自检不会因此 FAIL**。

## 窗口与分辨率

窗口**可以任意拉伸、最大化和全屏**，画面不会变形、不会留黑边：

| 行为 | 说明 |
|---|---|
| 缩放 | 整个 2D 世界随窗口等比缩放；分辨率越高，画面越大越清晰（文字保持可读） |
| 比例 | 逻辑空间按窗口比例扩展（`expand`）：比 16:9 窄则向下变高，比 16:9 宽则向右变宽 |
| 棋盘 | 9×5 草坪取「可用区域能容纳的最大正方形格」，整体居中；窗口变化时单位一起重排 |
| 上下信息条 | 永远贴住窗口上下边缘，卡片与按钮随草坪左缘对齐 |
| 最小窗口 | 640 × 400（再小文字会看不清，已被锁住） |

> 拉伸策略是在**游戏启动时用代码设置**的（`Game._apply_window_policy()`），
> 不依赖 `project.godot` 里的设置——因为 Godot 编辑器会用自己的内存设置重写那个文件。
> 想改设计画布尺寸，改 `Balance.WINDOW_SIZE` 并同步 `project.godot` 的 viewport 尺寸。

想验证：把窗口拖成 4:3 / 16:10 / 21:9，或按 `F11` 全屏，然后看控制台里每次都会打印的新几何
（`[Layout] viewport ... cell ... lawn ...`）。

## 怎么玩

| 操作 | 说明 |
|---|---|
| 点植物卡片 | 选中召唤卷轴（也可按 `1`–`6` 按槽位选）。**卡片从花园召唤**该名称的随机一株，用完要等冷却；**每回合默认只能用 1 张卷轴**（关卡可调成 2） |
| 点草坪格子 | 在选中卡片后种下植物；空的可放置格会泛绿、不可放置格泛红 |
| **END TURN** | 结束操作阶段，结算本回合（等价于按 `SPACE`）。**下一回合会还你 1 张召唤卷轴** |
| 右上角 `SETTINGS` | 在**战局之上**打开设置页；`BACK` / `ESC` 回到**原来那一局**（不会重开、不会丢场上单位） |
| 右上角 `RETREAT` | 撤退：结算花园并回主菜单。**要点两次**（第一次变 `CONFIRM?`，3 秒内再点一次；超时自动取消） |
| 按 `ESC` | 取消当前选中 |

回合流程：`回合开始（波次入场 + 还你召唤卷轴）→ 操作阶段 → 植物自动行动 → 僵尸行动 → 回合结算`。
僵尸走到最左列就会开始啃脑子，**脑子 HP 归零即失败**；清完全部波次即胜利。

> **撤退为什么要确认**：撤退会把这一局的伤势**写回花园**（和按 `M` 回主菜单一样），
> 误点一次就可能让植物永久带伤。胜负已分之后再点 `RETREAT` 则一次即走。
> 想"撤销这一局"请用 `R` 重开 —— 只有 `R` 不结算，所以只有 `R` 会回滚花园（完整按键见 `PROMPT.md` §8）。

### 主菜单

- 一列按钮，顺序：**战役入口**（有存档时裂成「继续战役」+「新的战役」，后者要二次确认，旧档会被覆盖）
  → **自由关卡**（关卡列表）→ **生存模式**（未实装，只回一句提示）→ **图鉴** → **设置** → **退出**。
- **地上四件东西可以直接点**：水壶 = 花园、木箱 = 仓库、钥匙 = 商店、背包 = 背包。
- `L` 键在前端任何地方**直达关卡列表**。

### 战斗页

- **上 HUD**：阳光 / 回合 / 脑子 HP / 僵尸计数 / 下一波 / 阶段 / 关卡名；
  右上角是 设置 · 背包（`P`）· 撤退（`M`，两击确认）。
- **下条**：行标签 + 植物卡行 + 工具行 + 跨两行的 **END TURN**。
- **种一株**：点卡片 → 点草坪格子。召唤要同时满足五件事（拥有卷轴 / 本回合还有额度 / 卡冷却转完 /
  花园里有可用的一株 / 阳光够）；**被拒绝时什么都不消耗**。灵界卡不需要花园里有株。
- **卡片角标**：`园` = 从你花园里那一株来的（带着它当前的血，打完回花园）；
  `灵` = 临时复制体（打完就消失，不计经验）。
- **工具**（铁锹 / 手套 / 锤子）走**充能**：起始 0、每回合 +1，到阈值才亮，用掉归零；目标非法不消耗。
- **结束回合**：植物先动、僵尸后动；每回合自然加阳光。
- **打完**：结果面板给统计、奖励、背包与钱。

### 五个前端页

- **花园**：4×4 = 16 个花盆；右上角四格道具栏，操作是**"拿起来 → 点植物"两段式**
  （右键或再点同格放下）；右侧是详情（名称 / 等级 / 生命 / 状态 / 天赋）。
- **仓库**：掉落的东西先落这里。**钱要手动卖出来**（"卖出整叠" / "卖出所有钱币"）。
- **商店**：把卖来的钱花掉（肥料 / 经验药水 / 植物 / 天赋药剂…）。
- **背包**：从主菜单进是只读视图；**战斗里按 `P` 打开的是战内背包**，能量豆在那里用。
- **图鉴**：四个页签（植物 / 僵尸 / 道具 / 关卡），一行 8 格，右上角有贴图与详情。
  图鉴**不发明数据**——没实装的会如实写"尚未实装"。
- **`ESC` 的规则**：菜单 / 关卡列表 / 设置 → 回上一页；花园 / 仓库 / 商店 / 背包 / 图鉴 → 回主菜单。

### 按键

常用：`SPACE` 结束回合 · `1`–`6` 选第 N 张卡 · `8` `9` `0` 选工具（铁锹 / 手套 / 锤子）·
`P` 战斗背包 · `ESC` 返回 · `F11` 全屏 · `L` 关卡列表 · `ENTER` 激活主菜单地上的东西。
**完整按键表（含调试键）见 `PROMPT.md` §8**，本文不维护第二份。

## 遇到问题怎么办

| 现象 | 先看哪 |
|---|---|
| 启动日志里有 `FAIL` | `docs/DEV.md` §8（自检与排错）：每个模块各打印自己的判决行，**看 `FAIL` 不看行数** |
| 规则不对 / 想确认某条语义 | `PROMPT.md`（规则唯一权威） |
| 数值不对 / 想调手感 | 改 `data/units/*.csv`、`data/items.csv`、`data/level/*.json`（改表即可，不用动代码） |
| 新关卡不出现 / 关卡顺序 | 在 **`data/levels.csv`** 里加一行（`json` 列指向那个文件，顺手填名字/难度/音乐）——**那张表才是关卡名册** |
| 贴图不出现 | `docs/UNIT_ART.md` §6：查得到路径但文件没画 → 只计数不报错，游戏用色块顶上 |
| 中文变成豆腐块 | 字体没装好 → 游戏整体回落英文名（`docs/ARCHITECTURE.md` §7） |
| 音乐 / 音效不对 | `docs/ARCHITECTURE.md` §6 |
| 存档读不出来 | 坏档会被改名 `.bak` 保留，游戏用默认档继续（`docs/DEV.md` §8） |
| 全屏点了没反应 | 已知环境限制（编辑器内嵌窗口 / 某些 Wayland 合成器）→ 自动降级为无边框铺满 |
