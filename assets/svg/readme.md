# PvZ Turn-Based 占位素材库（SVG）

> 统一管理所有占位 SVG，保证视觉风格一致，方便后续替换为融合版素材。

---

## 1. 目标

- 所有占位素材使用 **扁平几何风**，无渐变、无阴影、无描边。
- 统一画布与导出尺寸，确保在 Godot 中与 96×96 网格对齐。
- 统一命名与目录结构，方便查找、替换、扩展。
- 当前素材仅用于 MVP 逻辑验证，后续可整体替换为融合版真实素材。

## 3. 视觉规范

### 3.1 画布与尺寸

svg画布:
	width="128" 
	height="128" 
	viewBox="0 0 128 128"
留白：
	从底部向上延展16单位作为平地线，避免贴边，也是影子投射的位置。

### 3.2 风格

- **扁平化**：纯色填充，无渐变、无阴影、无高光。
- **几何化**：使用圆、椭圆、矩形、多边形、简单路径。
- **无描边**：不添加 `stroke`，除非是图标内部线条（如脑子褶皱）。
- **简单优先**：能用一个形状表达就不用两个。
- **颜色统一**：所有颜色必须从下方调色板选取。

### 3.3 体态
侧视朝右。

### 3.3 调色板

### 3.4 线条与细节

- 内部细节（如脑子褶皱）使用同色系深色，`stroke-width="3"`，`stroke-linecap="round"`。
- 不添加外部轮廓描边。
- 眼睛、嘴巴等可选，但必须极简（小圆点或短线）。

## 4. 动画规范
默认推荐表
动作	名称	推荐时长	说明
idle	循环	2.0 ~ 4.0 秒	呼吸/轻微晃动，太长会显得呆，太短会抽搐
walk	循环	0.6 ~ 1.0 秒	一个完整步态周期（左右各迈一步）
run	循环	0.4 ~ 0.7 秒	比 walk 快，步频更高
jump	一次性	0.3 ~ 0.5 秒	起跳上升部分；下落可另做或复用
hit	一次性	0.2 ~ 0.4 秒	受击硬直，要短促，否则影响操作
dead	一次性	1.0 ~ 2.0 秒	倒地过程，可停在最后一帧
attack（近战）	一次性	0.3 ~ 0.6 秒	前摇 + 命中 + 后摇
shoot（远程）	一次性	0.3 ~ 0.5 秒	抬枪/拉弓 + 发射 + 收势
lose	一次性/循环	1.0 ~ 3.0 秒	失败姿势，可循环轻微晃动
win	一次性/循环	1.0 ~ 3.0 秒	胜利姿势，可循环

## 4. 命名规范

- 全部小写，用下划线分隔。
- 格式：`类别_名称_变体.svg`
- 类别：`plant`、`zombie`、`icon`、`prop`、`ui`
- 示例：
  - `plant_peashooter.svg`
  - `zombie_basic.svg`
  - `icon_sun.svg`
  - `prop_jar.svg`

> 当前目录中部分文件名为简化名，后续可逐步迁移到上述规范。

## 6. 在 Godot 中的使用

1. 将 SVG 放入 `assets/placeholder/svg/` 对应目录。
2. Godot 导入时设置：
   - **Scale**：`0.96`（使 100 单位 → 96 像素）
   - **Filter**：关闭纹理过滤（保持像素清晰）
3. 在 `unit.gd` 的 `_build_visual()` 中加载：
   ```gdscript
   var tex = load("res://assets/placeholder/svg/units/peashooter.svg")
   var sprite = Sprite2D.new()
   sprite.texture = tex
   add_child(sprite)
   ```
4. 使用 `modulate` 调整颜色（如受击闪白、冰冻变蓝）。
5. 表现层动画（Tween、Shader）不修改 SVG 本身，只在 Godot 中叠加。

## 7. 新增素材流程

1. 从调色板选色，保持扁平几何风。
2. 使用 `viewBox="0 0 100 100"`，导出 96×96。
3. 按命名规范保存到对应目录。
4. 更新本 README 的素材清单。
5. 在 Godot 中测试缩放与对齐。
6. 提交前检查：无阴影、无渐变、无多余描边、颜色在调色板内。
