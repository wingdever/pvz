> 两条特效同时发生时谁赢、"单位自己有动画时"谁让位——即特效的**规则语义**。

## 1. 一句话与分类：五种看起来都叫"特效"的东西

一句话：**具名特效是每个身体都会做的姿态；棋盘图画是草地上的一次画面；
光束是两个身体之间的一条线；被吞是挂着的一种状态；旋风是一块会走的地方。**

判据是**寿命**，不是"看起来像不像特效"：

| | 具名特效（姿态） | 棋盘图画 | 光束 | 持续状态（被吞） | **行走的区域**（旋风） |
|---|---|---|---|---|---|
| 它是什么 | 一个**身体**的姿态 | 草地上的一张**画** | 两个身体之间的**一条线** | 一个身体**挂着的样子** | 草地上**会走的一块范围** |
| 活多久 | 一个身体的一生（要跨过死亡、要让位给真动画） | 一次动画（0.2 ~ 0.9 秒） | 一闪 0.14~0.42 秒；通道跟满一整场大招 | 挂多久由消化决定 | 走完表行点名的**距离**（乱斗 30 Hz 定步长；秒是结果，不是设定） |
| 跟着谁 | 那个身体 | 那一块**地方** | 生成时取一次的两个端点（光不追人） | 那个身体 | **谁也不跟**——它被召唤出来就独立了，像射弹 |
| 谁清理它 | 身体自己（`_dying`） | `Fx.clear()`（棋盘拆掉时） | 同上（通道由竞技场收回） | 吞噬者结束时撤销 | 竞技场（`Brawl.tornadoes`：`restart()` 与落幕各清一次） |

**[B39]/[B41] 第五种是旋风（鸟怪的普攻），而它的分类判据仍然是寿命**，四条否定说清了它是什么：

- 它**不是具名特效**：它不摆任何身体的姿态，因此完全不参与 §3 的优先级——
  **召唤它的鸟倒下了，旋风照旧走完它那段距离**（与射弹同一条规矩：那一击早已出手）。
- 它**不是棋盘图画**：图画落在**一块不动的地方**、由 `Fx` 那一层持有并在棋盘拆掉时一次性清空；
  旋风**自己走**、由**竞技场按定步长一 tick 一 tick 地推进**，是 `shots` / `beams` / `gulps` 之后
  第四个这样的 timed object。**同一格地方不会"叠十张旋风"**——它会离开。
- 它**不是光束**：光束连的是两个身体，旋风谁都不连；但它的**伤害节拍**是光束/吞噬那一族的做法
  （一拍一笔、全额走召唤者自己的 `land_hit()`，绝不另开一张伤害表）。
- 它**是招式自己的一层**：语义上"这一击化作一块范围"（`旋风` 那一格写的就是它走多远），
  与 `吞噬` 一样是**替换**接触、而不是附加在接触上。

⚠ **准确地说它是"身前召唤"而不是"发射"（[B41]，用户点名）**：旋风走的是**召唤者自己的朝向**，
不是"画到某个受害者身上的那条线"——它是天气，不是弹。落地实现：竞技场**不把目标交给它**。

两条推论：

- **一个身体同时只能摆一种姿势，但同一块地方可以叠十张画，而一个身体可以召出三块会走的地方**
  ——优先级那套（§3）只对姿态有意义，对图画与旋风都是空话。
- 图画**不跟着受害者走**：它落在挨打的那一点，而受害者被 `hit` 推开了约 `ANIM_SHAKE_DIST`。
  一张 70 px 的记号上这点错位看不出来；要它贴住身体，就得让 `Fx` 持有 `Unit` 引用，
  而那正是这个模块刻意不做的——**图画要能活过它画的那个身体**。

**数字（飘字）与图画同族**：太阳 +N、破甲、啃脑、被吞、伤害……都是"跟着那一块地方"的一次画面，
不改变任何身体的姿态，也不跟优先级那套打交道。**回合制用得少**（太阳、破甲、啃脑、吞噬各一处），
**乱斗是它的主场**：[B12] 每一次命中都冒一个 `-N`——那是乱斗**唯一**的数字读数。
⚠ **别把百分比流血也画上去**：乱斗的狂暴每秒都在扣血，一条 `-N` 一秒几次会把屏幕糊住
（所以漂字挂在"落地的一击"上，而不是挂在每一次掉血上）。

**光束有"一闪"与"通道"两种用法**：一闪生成即忘；通道由竞技场持有、跟着两个身体跑满大招全程。
⚠ 通道是**唯一**会跟人走的这一族——这不与"图画不持有 `Unit`"冲突，因为它根本不在 `Fx` 那一层上
（图层归属的判据见 `docs/dev/FX.md` §9）。

## 2. 通道与三条形状约定

一条具名特效由这些**通道**组成（变量与代码归宿在 `docs/dev/FX.md` §1）：
**红闪** / **倾斜**（前倾、后倾）/ **位移**（前冲、后退）/ **游走**（呼吸）/ **形变**（[B33] 纵长横扁、[B34] 果冻压扁回弹）/ **淡出** / **倒点**（绕哪儿转）。

四条**形状上的约定**：

1. **倾斜只转身体**。名字、血条、行动条画在它之后，永远**不**跟着一起歪。
   视图场景与贴图、色块三级兜底必须绕**同一个中心**转——否则同一张图在三级兜底里会歪得不一样，
   所以旋转中心是**单位中心**而不是零件原点的**脚底**。
   ⚠ **只有两处例外：倒地与眩晕的晃动（[B33]）。** 转 90° 还绕着中心，尸体就**悬在半身高**的
   草地上——所以这两条把旋转中心挪到**脚底**（锚点规则见 §4）。脚底永远在镜像轴上，
   所以 [B16] 的翻转与它不打架。活着的时候——除了那条晃动——这个锚点一直是 0，
   受击 / 出手的姿态因此**一个像素都没变**。
2. **姿态是"弹进去、缓回来"**：先把身体摆到姿势上，再补间回正。
   缓**入**的受击看起来像被推了一把，不像挨了一下。
   ⚠ **[B33] 的眩晕是这条唯一的反例**：它不"弹进去"，它**来回晃**——一个来回就是一段，
   一段比一段小，最后回到直立。因为它演的不是"挨了一下"，而是"站不稳"。
3. **红闪不进特效表**（**D2**，2026-10-05 落地时的决定）：红闪是**伤害反馈**，不是姿态，
   任何一次受伤都会闪（含工具、掉血、溅射邻居），与"这个单位有没有自己的受击动画"无关；
   表里的姿态列（`lean` / `push` / `sway` / `jelly` [B34] / `time`）才是姿态。这样将来某个单位长出真动画时，
   它让位的是**姿态**，不会连"被打到了"这件事都不说。
4. **[B33] 形变绕脚底、而且永不写节点缩放**。一具身体"变长再变扁"是**画**的形变，
   不是那个 Node2D 的 `scale`——后者已经被两件事占用（倒地的补间、被吞进肚子时的大小），
   谁再去写它，三方就会互相改写。形变与倾斜共用**同一个**变换，所以三级兜底画出来是同一个形状，
   而名字与 bar 照旧在变换之外（第 1 条）。
5. **[B34] 受击的果冻与空闲的形变是同一个通道的两个写手**。果冻不是新姿态：它是把
   [B33] 那条"画的缩放"**乘上**一个受击瞬间开始的阻尼振荡——**压扁 → 回弹 → 小压扁 → 回原形**，
   绕的还是**脚底**（第 4 条），所以两个模式都看得见（§7）。它**只挂在 `hit` / `hit_shot` 上**
   （被啃一下与被射一下都演，射弹按 `FX_PELLET_SCALE` 震得轻一点），出手与眩晕不演。
   ⚠ 与第 2 条同一个理由：挨一下的身体要**立刻**弹到位，不是缓进去。

## 3. 具名特效表与优先级

| id | 什么时候 | 优先级 | 组成 | 数值业主（`BalanceUI`） |
|---|---|---|---|---|
| `death` | 单位倒下 | **100** | [B25] **一种表演**（默认 倒地 → 淡出），走完 `queue_free` | `DEATH_*` + `ANIM_DEATH_TIME`，见 §4 |
| `hit` | 被**啃**了一下 | **30** | 后倾 + 后退 + **[B34] 果冻**（压扁回弹的阻尼振荡） | `FX_HIT_LEAN` / `ANIM_SHAKE_DIST` / `ANIM_SHAKE_TIME` / `FX_JELLY_*` |
| `hit_shot` | 被**射弹**打中 | **25** | 同上，乘 `FX_PELLET_SCALE` | 同上 × 0.6（果冻的幅度也乘这同一个 0.6） |
| `stun` | **[B33] 站不稳**（**今天还没有触发点**，见 §5） | **22** | 绕脚底**来回晃**（一段比一段小）→ 回直立 | `FX_STUN_LEAN` / `_SWINGS` / `_SWING_TIME` / `_DAMP` |
| `attack` | 自己出手 | **20** | 前倾 + 前冲 | `FX_ATTACK_LEAN` / `ANIM_LUNGE_DIST` |
| `idle` | 基线（没事发生） | **0** | **一种表演**（默认 [B33] 形变；旧的呼吸仍在表上，见 §3b） | `IDLE_STRETCH_*` / `IDLE_*` |

- **"前 / 后"是相对朝向的**，不是相对屏幕的：花名册里的植物朝右、僵尸朝左
  （乱斗里由驱动器每帧写入，可以是转身的、也可以是斜的）。
  所以**一行表同时描述植物和僵尸**，调用点一个方向数字都不用写。
- `hit` 为什么比 `hit_shot` 高：**正在被啃的身体，不该被同一帧落下的一颗豌豆打断动作**。
- **[B33] `stun` 为什么夹在 `hit_shot` 与 `attack` 之间**：挨了一下要盖过"我晕"（伤害反馈优先），
  而"我晕"要盖过"我出手"（一个站不稳的身体不该同时演前冲）。**22 是拍的第一版**，
  等真的有眩晕机制（哪个招式会晕人、晕多久）时再对着手感调。
- `idle` 不是一次性特效，是个**状态**：`play_fx("idle")` 的意思是"回到基线"，所以它没有时长。
- **[B34] 果冻不进乱斗的"位移失效"**：`hit` 在乱斗里被击退调用时照常演——被**推**的那一半
  照旧被网格门拒掉（§7），但形变那一半改的是**画**，不是 `position`，所以被推的身体也弹。

### 优先级与打断（**同级重启**）

```
死亡 100  >  受击 30  >  被射 25  >  眩晕 22  >  attack 20  >  空闲 0
```

- 新来的**严格高于**正在演的 → 顶掉它，重放。
- 新来的**同级（同一个 id）** → **重放**（从当前值重来，杀掉旧的表现）。
- 新来的**更低** → **整个丢掉**，正在演的不受影响。
- 死亡进行中只认 `death`：**死人不再抽搐**。
- 空闲被压住时**不是冻住**：基线会自己**松手**——呼吸的偏移与 [B33] 的形变都**滑回原位**
  （`FX_IDLE_STANDDOWN`），但相位停在原地，所以特效一结束，基线接着原样继续、不会跳一下。

### §3b. 空闲的两种**表演**（[B33]，用户 2026-10-08 定的默认：伸缩）

与死亡同一个形状（§4）：**基线在优先级表里始终只有一行**（0），但"一个身体没事干的时候长什么样"
是一张表演表：

| 名字 | 演什么 | 数值业主（`BalanceUI`） |
|---|---|---|
| `stretch`（**默认**） | 画面**纵向伸长 + 横向拉扁**，再反过来，绕脚底来回 | `IDLE_STRETCH_AMP` / `IDLE_STRETCH_SPEED` |
| `breath` | B33 之前的样子：上下浮动 + 左右微摆 + 3% 压扁 | `IDLE_BOB` / `IDLE_SWAY` / `IDLE_BREATHE` / `IDLE_SPEED` |

- **谁选**：只有**调用时机**能选（`set_idle_fx()`），不传就是默认。与死亡表演同一条规则：
  **单位自己不许挑**（§9），要按单位数据控制就先改 §9 再动这条链。
- **两种表演不叠加**：穿了 `stretch` 就没有浮动与微摆——那一条演的不是"身体在动"，
  而是"身体在变形"，两个一起动只会读成抖动。
- **形变绕脚底**（§2 第 4 条）：伸长时如果绕中心转，脚就会陷进草里、或者整个身体飘起来。
- **两个模式都生效**（§7）：形变与倾斜都是"画"的变换，不是位置，所以乱斗的身体照样伸缩。
- ⚠ 旧的 `breath` 那一行**没有被删**：它是 `IDLE_*` 那几个常量的读者，也是第一个带真动画的零件
  出现之前**唯一**能让一株植物"看起来不像默认值"的退路。
- **[B34] 果冻不与这一族竞争**：它不是第三种空闲表演，而是**受击**挂在同一个形变通道上的
  一次乘法——穿了 `breath` 的身体挨一下照样弹（那一支本来就写 `Vector2.ONE`，果冻乘它不变）。

## 4. 死亡的两种**表演**（[B25]，用户 2026-10-08 定的默认：倒地并淡出）

`death` 在上面那张表里**仍然只有一行**（优先级 100，尸体不与任何东西争）——
但"一个身体怎么花掉它最后一秒"是一张表演表，不是一句写死的话：

| 名字 | 演什么 | 数值业主（`BalanceUI`） |
|---|---|---|
| `topple`（**默认**） | **向后**倒在脚底上 → 稍微过头 → 落平 → 就地淡出 | `DEATH_TOPPLE_ANGLE` / `_TIME` / `_OVERSHOOT` / `_SETTLE_TIME` + `ANIM_DEATH_TIME` |
| `fade` | 站在原地淡出 + 缩小（B25 之前的样子） | `ANIM_DEATH_TIME` + `DEATH_FADE_SHRINK` |

- **谁选**：只有**调用时机**能选，不传就是默认。铲子（挖掉一株植物）点 `fade`——
  **一株被拔出来的植物没有倒下**，让它就地消失才对。
- **朝向是相对身体的**：倒的符号和 `hit` 的后倾一致（负 = 向**后**倒，背离它正对着的东西）。
  所以植物与僵尸、以及乱斗里任何朝向的棋子，**同一行表都说得通**，调用点不写方向。
- **倒地的中心是脚底**，不是单位中心（§2 第 1 条的例外）；淡出**不再带缩小**——
  一具平躺的身体是**一个身体**，不是泄了气的气球，缩小还会把它从刚够到的地面上拽起来。
- **三段时长是串行的**（fall + settle + fade ≈ 0.74 s），那就是观众等的总时长。
  ⚠ 改总时长之前先想乱斗的**落幕幕布**（`BalanceBrawl.BOUT_CURTAIN_SECONDS` = 0.9 s）——
  落幕必须**盖过**一次完整的死亡，不然 [B23] 解决的问题会**换个样子**回来。
- ⚠ **单位自己不许挑表演**（§9 那条"不做每个单位一套特效参数"照旧有效）：`fade` 是**调用时机**的
  选择，不是某个单位的属性。哪天要按单位数据控制（`units.csv` 加一列 `死亡特效`），
  那是先改 §9 的决定、再动这条链。

## 5. 触发时机（什么时候放）

| 事件 | 放的是 |
|---|---|
| 僵尸啃咬 | `attack`（自己）+ `hit`（被啃的那株）+ **图画**（由挨打方的表行决定，见 §8 与 `docs/dev/FX.md` §5） |
| 僵尸吃脑 | `attack` |
| 射弹命中 | `hit_shot`（受害者） |
| 乱斗里出手 | `attack`；**近战**落点 = 火花（人人有）+ 图画（由**出手方**的表行决定） |
| **乱斗里命中**（[B12]） | 一个**数字** `-N`——它不是具名特效，是 §1 那一族 |
| **乱斗里被吞噬**（[B10]） | `hit`（**只有被吞的那个身体**，在进肚子那一帧）；之后挂着的是**状态**（§1） |
| **乱斗里被击退**（[B9]） | `hit`（**只有被推的那个身体**）；乱斗里生效的只有**后倾**那一半（§7） |
| 倒下 | `death`，表演默认 `topple`；**铲子**点名为 `fade`（§4） |
| **眩晕**（[B33]） | `stun` —— **今天没有任何触发点**：仓库里还没有"会晕人"的招式、道具或状态，所以这条特效是**表先于机制**的一行。门已经开好（`play_fx("stun")`），等哪个游戏机制回答"谁晕了、晕多久"；**不要**为了让它看得见而塞一次临时调用，那是测试脚本要做的事（`AGENTS.md` §2） |
| 空闲 | 基线一直开着（默认**形变**，§3b），被上面任何一条压住就停 |

**红闪不在这张表里**：任何一次受伤都会闪，这与"有没有具名特效"无关（§2 第 3 条）。
具体在哪个 `file:line` 触发，是接线事实，清单在 `docs/dev/FX.md` §2。

## 6. 兜底：单位**自己**有动画时，特效让位

这就是这套东西存在的理由——**"单位如果没有受击动画，才施加受击特效"**。
判据**不写在清单里**，而是**问身体自己**：视图场景里有一条**同名 clip**（`hit` / `attack` / …）
就播它，通用姿态一步都不做；没有就按表来。**问身体、不问清单**：某个零件哪天长出 `hit` clip，
它应当**当天**就被这条问句发现，而不是等谁想起来去登记一次。

⚠ **这一段今天还没有被真正走过**：登记的零件里没有任何一条带这些 clip，所以所有单位都走通用分支。
第一个带 `hit` clip 的零件落地时要补的事，记在 `docs/dev/FX.md` §3。

`death` 是**唯一不吃这条让位**的特效：它的最后一段（淡出）同时是"什么时候清除尸体"的时钟，
交给一条 clip 去演，草地上就会永远躺着一具尸体。**[B25] 加了倒地也不改变这件事**——
两种表演都**必须**以淡出收尾。

## 7. 两个模式：网格与乱斗

`Unit` 是两个模式**共用**的身体（乱斗只持有它），所以特效也共用。规则：

- **倾斜两个模式都生效**。旋转不是 ink，不需要格子。
- **[B33] 形变与晃动同理，两个模式都生效**。它们改的都是**画**的变换（以及视图零件的姿态），
  不是身体的坐标——所以乱斗里一株植物照样伸缩、一个棋子照样能被晃得站不稳。
  ⚠ 但**位移**（具名特效的 push 通道）照旧只在网格里生效（下一条），别把这两件事混起来。
- **位移只在网格里生效**。乱斗里出手是**只有前倾、没有前冲**——这是约定，不是 bug。
- 乱斗的身体多一个事实：**朝向**。"瞄哪"与"画朝哪"是两件事（[B16]）：
  瞄准永远指向敌人，而**画本身朝哪**由身体自己说、站错半场时翻过来
  （规则见 `docs/prompt/BRAWL.md` §8.15）。翻转只动**身体**：
  名字、血条与两条 bar 永远不跟着翻。
- **[B9] 乱斗自己有一条真位移**：击退**不走**具名特效的 push 通道——被推的身体是**真的换了地方**，
  不是画上去的偏移，所以它与"位移只在网格里生效"不矛盾（那条说的是**具名特效的 push 通道**）。
  姿态上它只借了 `hit` 的后倾那一半。

## 8. 哪些不是具名特效（保持原样，别"顺手统一"）

**某一招自己的编排**留在那一招里：

| 特例 | 为什么不是具名特效 |
|---|---|
| 巨人的锤击 | 抡起时身体**向下**沉、受害者被**向上**抛——既不是"前"也不是"后" |
| 三件套里的锤子 | 同上，工具砸下来是把僵尸往下压 |

判据一句话：**"前倾 / 后倾"能描述的是具名特效；需要一个具体方向的，是招式。**

**近战图画用哪张，由"是谁打的那一下"决定，而这件事写在单位的表行里**——不写在本文、也不写在代码里：

| 谁 | 哪张表的哪一格 | 值 |
|---|---|---|
| 民兵 / 骑士 / 队长 | `data/units/humans.csv` 的 **`近战特效`** 列 | `slash` / `slash_heavy` / `slash_divine` |
| 每一种僵尸 | `data/units/zombies.csv` 的 **`default` 行** | `claw`（一行答全部："所有僵尸都抓"是**一格**，不是 44 行） |
| 盾兵 / 植物 / 没点名的 | 空着 | 空 = **只出火花**，不是错误 |

**光束同理**：id 由 `data/units/monsters.csv` 的 **`远程特效`** 列点名（四个 id：
`laser` / `flame` / `impulse` / `thunder`，各自长什么样是 `BalanceUI.BEAMS` 与代码的事，
见 `docs/dev/FX.md` §6）。⚠ **与近战图画不同：光束的 id 写错不静默**——
这一击本来就是光束，画不出来就等于没有反馈，所以回落到最朴素的那张（`laser`）并在日志里喊一声。
⚠ **端点只在生成时取一次，光不追人**：理由写在 `docs/prompt/BRAWL.md` §8.9 ④（与 D61 同源）。

**[B14] 出手点也可以由这张表说**：一条光默认从**身体中心**出去，
而**雷从雷角兽左上角那只角上出去**——出膛点按**棋子画框的比例**给，
因为乱斗会把棋子画大。**一闪与通道共读同一个答案**，所以同一条 attack 只有一个出膛点；
通道还会**每帧重读**，于是走着放雷的身体**带着角走**。

**[B14] 同一个通道也被大招用**：`大招持续` 有数的棋子攒满能量后开的就是这条通道，
只是每跳值一整下。**画这一层完全不知道普攻与大招的区别**——它只知道 id 与那一跳多少钱
（见 `BRAWL.md` §8.13）。

**[B39]/[B41] 旋风是"一块范围"，所以它有一条别的特效都没有的诚实约定**：
**画在草地上的最宽那一圈，必须正好是伤害判过的那一圈**（半径 = `TORNADO_REACH_CELLS`），
它向上可以画得**矮**于自己占有的空气（`z_thickness`），但绝不可以画得**更高**——
"这一块范围会打到你"是观众唯一需要的承诺，画得比规则大就是撒谎（B20 那条，落地与 slam 圈同理）。
**体型那一档买的是空气与密度，不是宽度**（[B40]）。

**[B41] 一条特效可以有两套画法，而它们共用同一把尺子**：默认的画法是**序列帧**
（`assets/svg/fx/tornado_0.svg` / `tornado_1.svg`，80 ms 一帧），备选是**纯代码画的那根柱子**。
换的是**工具**，不是**规则**——两套都钉在同一个环上、都不越过自己的 `z_thickness`，
所以"改画法"不需要动任何数值，而"改数值"两套一起跟着变。
⚠ **两套素材文件读不到时自动退回代码画法**：坏画可以，看不见不行
（这一批要杀的正是"完全看不到旋风"，一个缺文件不许变成它的第二次发作）。

## 9. 明确不做

- **不做状态机、不做特效队列、不做对象池**。理由与棋盘图画同一句：
  池化 / 排队都是"同一批节点的第二个业主"，**直到有测量出来的理由**再建。
- **不做"每个单位一套特效参数"**。今天所有单位共用一张表；某个单位要不一样，
  正确的做法是让它长出**自己的动画**（§6 的让位门），而不是给它在表里开一行特例。
  **[B25] 的死亡表演与 [B33] 的空闲表演都不违反这条**：它们是**调用时机**在两种既定演法里挑一个，
  不是某个单位自带的参数；哪天要按 `units.csv` 的某一列控制，先来改这一条。
- **射手开火不加 `attack`**。加特林一秒四发，前倾会变成抽搐。
  "谁算出手"由触发时机决定，今天只有 §5 里那几处。
