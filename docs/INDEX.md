## 6. 更新规则

1. **增删任何文档 ⇒ 当天同步本文件**（§1/§2 各一行）；**历史档案**在 `docs/history/`，同步它的分布表 `docs/history/README.md`。
2. 现行文档（`PROMPT.md`、`docs/ARCHITECTURE.md`、`docs/DEV.md`）与档案：**默认不改**，见 `AGENTS.md` §6。
3. `docs/STATE.md`：**每批收尾必须更新**（阶段、读数、未结事项）。
4. 发现"同一个事实在两处各写一遍" ⇒ 先在本文件 §5 判据表里确认业主，再把副本改成指向业主的那一句；
   不要两边各改一半——那就是这份文件诞生的原因。
